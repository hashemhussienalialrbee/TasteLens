
# TasteLens – Graduation Project

TasteLens is a mood-based recommendation system that suggests food places and activities based on user mood and preferences.

## Project Overview
The system collects user mood and preferences, analyzes the data, and generates personalized recommendations using structured data models.

## Features
- Mood-based recommendations
- User preference analysis
- Structured relational database
- Recommendation logic
- User feedback support

## Role
**Team Leader**
- Led team coordination and task distribution
- Participated in requirements analysis and system design
- Designed database schema (ERD) and data flow diagrams (DFD)
- Applied SQL and system analysis techniques

## Technologies Used
- SQL
- Database Design
- System Analysis
- Data Modeling
